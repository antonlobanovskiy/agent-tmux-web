# v0.1.24 Release And GitHub Visuals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish v0.1.24 with professional current GitHub visuals, a smooth 30 fps showcase, and verified generic Android APK/AAB artifacts.

**Architecture:** Keep the actual product UI authentic by capturing only loopback demo mode, then composite those captures over a restrained image-generated abstract backdrop. Treat metadata, visuals, documentation, and publication as separate review gates; the GitHub release is created only after the release PR merges and all web/Android checks pass.

**Tech Stack:** React 19, TypeScript, Vitest, Playwright Chromium, Node.js, Pollinations image API, HTML/CSS composition, FFmpeg/ffprobe, Gradle, GitHub CLI

## Global Constraints

- Package version is exactly `0.1.24`.
- Android `versionName` is exactly `0.1.24`; `versionCode` is exactly `25`.
- Release tag is exactly `v0.1.24` and targets the merged release commit on `main`.
- Release assets include the generic public APK, generic Play AAB, and reviewed 30 fps MP4.
- Actual UI comes only from loopback `?demo=1` with repository fake data.
- Image generation produces only a dark abstract backdrop: no text, logo, terminal, person, device, or invented UI.
- Video is 1920x1080, 30 fps, H.264, `yuv420p`, CRF 18, no audio, and 12-18 seconds long.
- No GIF is published as the primary animation.
- Never capture or publish the private service, concept URL, token, personal path, live tmux data, upload, or server address.
- Intermediate frames, temporary HTML, API responses, traces, private APKs, and signing material are never committed.
- Source registry items continue to omit binary visual media.

Add a generator that fails closed:

```js
async function generateBackdrop() {
  const source = path.join(framesDir, "generated-backdrop-source");
  const output = path.join(framesDir, "generated-backdrop.png");
  const response = await fetch(IMAGE_ENDPOINT, { signal: AbortSignal.timeout(120_000) });
  if (!response.ok || !(response.headers.get("content-type") ?? "").startsWith("image/")) {
    throw new Error(`Image generation failed with HTTP ${response.status}`);
  }
  await writeFile(source, Buffer.from(await response.arrayBuffer()));
  await run("ffmpeg", ["-y", "-hide_banner", "-loglevel", "error", "-i", source, "-vf", `scale=${SHOWCASE_WIDTH}:${SHOWCASE_HEIGHT}:force_original_aspect_ratio=increase,crop=${SHOWCASE_WIDTH}:${SHOWCASE_HEIGHT}`, output]);
  return output;
}
```

The function must not contain a fallback generated gradient. A failed or visually invalid image-generation result stops publication.
