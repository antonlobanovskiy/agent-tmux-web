# Marketing Kit

## One-Liner

Agent Tmux Web is a mobile-first control panel for Codex, Claude Code, and other
terminal agents running inside tmux on your own server.

## Short Description

Run long agent sessions from your phone without SSH friction. Agent Tmux Web
keeps tmux sessions, raw terminal access, temporary file uploads, and configured
CLI launchers in one browser UI that works over Tailscale, a VPN, an SSH tunnel,
or a private reverse proxy.

## Key Points

- Mobile-first tmux control for terminal agents.
- Launch Codex, Claude Code, Gemini, or custom commands.
- Switch between normalized chat capture and raw tmux terminal mode.
- Upload files from Android or desktop browsers to temporary server paths.
- Designed for private networks, not public internet exposure.
